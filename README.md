# Distribuciones IBECO — copia de prueba GitHub Pages

Código recuperado de una página guardada en Chrome el 31-10-2026. Se eliminaron los elementos específicos del editor de ChatGPT y se reconectaron los recursos JavaScript, CSS y logo. **No se incluyeron clientes, movimientos ni respaldos privados.**

## Precauciones

- Esta copia utiliza `localStorage` del navegador bajo el dominio de GitHub Pages. Los datos **no se transfieren automáticamente** desde la aplicación original.
- Antes de importar datos reales, hay que probar operaciones ficticias y conciliar resultados.
- No publicar archivos `ibeco-respaldo*.json` en este repositorio público.
- Un enlace público a la aplicación **no protege** datos almacenados localmente si alguien obtiene acceso al dispositivo.
- No cerrar ni eliminar el acceso original de ChatGPT hasta terminar la validación.

## Instalación en GitHub

Subir el **contenido de esta carpeta**, no el ZIP ni una carpeta contenedora, a la raíz de la rama `main` del repositorio `Nixonjbc/ibeco-distribucion`. Usar `Add file → Upload files`. Reemplazar `index.html` existente.
